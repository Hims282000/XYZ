# Enterprise Social Media Analytics Platform 2\r\n\r\nScalable social media analytics platform.\r\n\r\n- Angular 16 + NgRx for state management and real-time visualization\r\n- Node.js microservices (Express.js) handling 50k+ API reqs/hour\r\n- Integrations: Twitter/X, Facebook, Instagram (placeholders)\r\n- Redis for rate limiting, caching, and pub/sub\r\n- MongoDB with aggregation pipelines for analytics\r\n- Real-time updates via Socket.io and WebSockets\r\n- Deployed on Azure AKS (manifests provided)\r\n\r\n## Services\r\n- backend/common: shared libs (Mongo, Redis, env, logging)\r\n- backend/api-gateway: REST + Socket.io gateway, rate limiting, auth stub\r\n- backend/ingestion: social API ingestion + queues\r\n- backend/analytics: analytics APIs backed by Mongo aggregations\r\n- frontend/esm-analytics-dashboard: Angular 16 app with NgRx\r\n\r\n## Local Development\r\n1. docker-compose up -d\r\n2. Install deps per service, run dev scripts\r\n3. Open Angular app on http://localhost:4200\r\n
